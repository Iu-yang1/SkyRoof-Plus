# 过境匹配：手动计算、UTC 时间范围与后台进度

在 SkyRoof 中选择 **视图 → 过境匹配**，搜索本台和对方电台共同可以看见目标卫星的时间窗口。

## 如何使用

1. 顶部选择卫星，填写对方的 Maidenhead 网格定位（例如 `OL79WQ`）。本台网格与海拔沿用 **设置 → 用户**；DX 海拔仍按海平面计算。
2. 在 **开始（UTC）** 与 **结束（UTC）** 中选择完整起止日期和时间，默认从打开面板时的当前 UTC 分钟起计算 14 天。**时间字段始终按 UTC 解释**，不使用电脑本地时区转换。
3. 按 **开始计算** 才会实际预测。编辑网格、日期、卫星或刷新星历，不再自动调用轨道预测。
4. 计算进行时显示进度条，依次报告本台过境、DX 过境、共同可见区间与天空轨迹计算。按钮此时为 **取消计算**，点击可取消。
5. 计算成功后一次性更新匹配列表，并保留 100% 进度；修改查询条件会清空旧结果，提醒重新开始。没有匹配窗口时显示 0 条。
6. 点击某一共同窗口，可以查看双方的完整天空轨迹和交集时段详情。

## 计算逻辑与响应性

- 本台与 DX 两个地面站的轨道预报、相交区间、11 点天空轨迹和 31 点最大仰角采样均在后台 `Task.Run` 执行，WinForms 绘制线程只操作界面状态及发布最终完整结果。
- 交集裁剪到所选 UTC 时间范围，保持原有至少 **30 秒**共同可见的筛选阈值。使用有序区间检索，避免逐个比较所有本台与 DX 过境组合。
- 取消信号在两次轨道预测之间以及相交和轨迹采样过程中检查；如果 Orekit 已进入无法中途取消的单次预测调用，需要等该调用返回后才能停止，但**不会阻塞 UI，也不会显示取消前的过期结果**。
- 地球静止卫星的可见结果按用户指定的整个时间范围构造，不再局限于从当前时间起的固定一天。
- 本功能计算的是共同几何可见性，**不表示转发器已开启或保证能完成 QSO**。

## 验证说明

使用源码 xUnit 验证输入不会触发预测、UTC 时间区间裁剪和边界、双语界面模拟 DPI（100/125/150/200%）。此测试不等同于实机天线或真实卫星通信验证。
