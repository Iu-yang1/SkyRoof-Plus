# IF→AF FM 接收链 P0–P3 迭代（2026-11-17）

## 目标及输入契约

源信号为 IC-9700/IC-705/IC-905 的 48 kS/s、实数 12 kHz IF；SkyFM 上游
`FmFrontEnd` 的输入为复数零中频 IQ，不能直接套用于此链。保留 SkyRoof 的四相 NCO、
复数通道 FIR 和相位差 FM 鉴频器。所有 FM 扩展只影响**模拟 FM 语音**，默认关闭。

借鉴上游：
- https://github.com/VE3NEA/VE3NEA.SkySignals/blob/main/VE3NEA.SkyFM/FmStreamingDiscriminator.cs
- https://github.com/VE3NEA/VE3NEA.SkySignals/blob/main/VE3NEA.SkyFM/FmFrontEnd.cs
- https://github.com/VE3NEA/VE3NEA.SkySignals/blob/main/VE3NEA.SkyFM/SoftSquelch.cs

## P0 — 语音/遥测的 PCM 分流

`IfAfDemodulator.Process(input, voice, clean)` 同时产出 48 kHz AF：
- `clean`：相位鉴频 → 7.5 Hz 直流抑制 → 既有 AF 低通，**尚未**语音去加重、
  250 Hz 高通、包络衰落插值、音频静噪及主机输出增益。
- `voice`：在 `clean` 的基础上叠加操作者启用的语音处理。
- `IfAfService.CleanDemodulatedAfAvailable` 提供额外可订阅事件；
  `DemodulatedAfAvailable` 保持旧语义（送往虚拟声卡的已增益 AF）。
  缓冲区由 ArrayPool 管理，订阅者在回调内复制。
- `TelemetryAudioReceiveSession` 的 `IfAfDemodulatedAf` 从旧的经语音增强事件
  改为新的 clean 事件，避免去加重和静噪改变数据样本。

**限制**：clean AF 仍使用当前 3 kHz（6.25 kHz 档为 2.1 kHz）AF 低通，
因此不应以它解调 9600 Bd GMSK 等宽带基带数据。对于这类调制，继续选择
`Shared12kIf`、`Capture12kIf` 或原始 SDR IQ，由 SkyTlm 直接处理。
`TelemetryAfskFmIqConverter` 的已鉴频 AF→重调频 IQ 桥接保持不变。
另外，独立/Loopback AF 输入已经在外部被处理过，不会自动获得 clean 契约。

## P1 — 语音滤波、去加重

`FmVoiceProcessing` 在旧的 `Off/Voice50us/Voice75us` 后追加
`Voice750us`（保留现有 0/1/2 JSON 枚举值），一阶低通实现去加重，
供与 750 μs 模拟预加重相匹配的 FM 语音选择。**不**自动假设任何卫星
都采用 750 μs；根据发射端预加重、接收机设置及录音 A/B 决定。

`FmVoiceHighpassEnabled` 为可选 250 Hz 二阶 Butterworth 高通，改善
低频噪声、67 Hz CTCSS 抑制。它是纯语音后处理；CTCSS 分析等需要低频
信息的链路不得使用该输出。

## P2 — FM 衰落处理与噪声静噪

`FmFadeBlankerEnabled` 启用 20 ms 语音缓冲和短暂 IQ 包络衰落插值：
- 包络单极跟踪 τ=100 ms，低于包络均值 0.5 倍判为低可靠样本；
- 衰落连续时标记相邻鉴频输出；仅当衰落结束且长度不超过 20 ms 时
  用衰落前后有效 AF 插值；
- 超过 20 ms 的长衰落放行原音频，不虚构恢复的语音信息；
- 固定附加语音延迟 20 ms；与 clean AF 采样**数量**一致，但时标有差异。
  同时启用语音静噪时，静噪增益也延迟 20 ms，避免把延迟后的语音起止点截断。
- 为保持旧有 AF 低通与数字分流，本实现是在语音 AF 滤波后执行的插值，
  与上游 `FmStreamingDiscriminator` 的**鉴频后/语音滤波前**插值位置不同，
  不能据此假定拥有相同实际音质收益。

静噪 `FmVoiceSquelchEnabled` 默认为关闭，开启后：
- `FmSquelchSource=CarrierPower` 继续原有功率判决；
- `FmSquelchSource=NoiseQuieting` 使用 **AF 低通之前**的宽带鉴频样本，
  3.5 kHz 二阶高通提取高频噪声并以 40 ms 平滑；
  噪声门限 `FmNoiseOpenDbfs` 默认 -18 dBFS，3 dB 滞后；
  同时要求已有 IF 载波功率门限满足，避免零输入被当作无噪声载波。
- FM 输出静噪继续采用约 10 ms 的增益渐变；**clean AF 不静噪**。

`FmNoiseOpenDbfs` 是**偏移归一化后的鉴频噪声功率**，不是接收机
RF S 表值，未经过 IC-9700 实机标定。只有手动启用 NoiseQuieting 时生效。

## P3 — 验证矩阵与后续实机验收

自动化 `IfAfFmVoicePipelineTests`：
- clean AF 与附加 750 μs/高通/blanker/静噪路径解耦且逐样本一致；
- 750 μs 高频衰减、250 Hz 高通对 CTCSS/语音的差异；
- 短衰落插值、长衰落不虚构、20 ms 输出延迟；
- 高频噪声 quieting 指标与模拟语音的区分；
- 任意分块输入的样本一致性；
- 默认设置及 JSON 序列化；
- 单秒 48 kS/s 合成 IF 的耗时诊断（非跨 CPU 的硬性能阈值）。
所有测试都属于模拟数据，不能冒充实际电台的 RF 灵敏度验证。

Windows 实机 A/B 建议：采集同一次 SO-50/AO-123/ARISS 过境的 12 kHz IF，
分别输出原始、仅 750 μs、高通、衰落插值和 NoiseQuieting 语音；
核对听感/客观噪声电平、有效呼号可辨识率、CTCSS、弱信号开关错误率，
以及 20/40/80 ms VAC 档下 DSP 排队与音频端到端延迟。同时保留
原始 IF，回归 SkyTlm 的 AFSK/FSK/GMSK/AX.25 CRC 或有效帧数。

本轮不改变射频 CAT、PTT、旋转器、卫星星历或遥测协议解帧算法。
