# SkyRoof-Plus UI P1–P4 验收记录（2026-11-14）

## 交付与约束

本轮以 v1.73 之后的 `master` 为基线，不改动 CAT、PTT、多普勒、旋转器状态机或卫星轨道算法。UI 强制保持原有控件顺序和窗口停靠拓扑；不使用额外滚动条、自动换行或按断点重排代替统一缩放。

## P1 — 顶部工具栏

- 以 WinForms 已进行系统 DPI 缩放后的控件树为统一基线，所有位置、尺寸、Padding、Margin 与字体由同一比例计算；非累积缩放避免反复放大/缩小造成数值漂移。
- `Tools → UI Scale`：75/85/100/110/125%。窗口宽度不足时统一缩小；卫星照片是唯一可选隐藏项。
- 模拟固定条幅测试：1280/1920 宽度、96/120/144/192 DPI。保存在 CI 的 `ui-dpi-layout-matrix` 附件中。

## P2 — Dock、专属右键面板

- `Tools → Dock & Popup Scale` 以独立比例缩放 Dock 内部控件与字体，不修改 DockPanelSuite 持久化窗口位置。
- Satellite Passes 自绘行高/路径线宽、Sky View 标签字体、Rotator RC-3040S 扩展高度及 G-5500 固定面板同倍率同步。
- 固定控件模拟测试检查 Dock 外框不变；G-5500 的 75/100/125% 控件几何和截图纳入同一 CI 产物。

## P3 — 窗口拓扑恢复及动态 DPI 可选模式

- 屏幕移除、显示器热插拔与工作区大小变化时恢复到最近的有效显示区，保留合法跨屏和负屏幕坐标。
- `--per-monitor-dpi` 或 `SKYROOF_DPI_MODE=PerMonitorV2` 可显式测试动态 DPI；默认维持 SystemAware，`--system-dpi` 可强制恢复。
- 主窗体 DPI 通知触发缩放基线重建；关闭正在按住方向键的手动旋转卡片时继续执行既有 STOP。
- 96/120/144/192 DPI、热插拔/拔屏/跨屏窗口边界由确定性单元测试覆盖。

## P4 — 模拟渲染与交互矩阵

通过 Windows CI 执行 WinForms `DrawToBitmap` 模拟截图和几何检查：

| 场景 | 宽度 / DPI | 断言 |
| --- | --- | --- |
| 顶部工具栏 | 1280、1920 × 96、120、144、192 | 统一缩放、字体/尺寸不漂移 |
| G-5500 弹出面板 | 75%、100%、125% | AZ/EL、STOP、TRACK、GO 控件不越界 |
| Satellite Passes、Sky View | 360、720 × 模拟 96/144/192 | 控件顺序和操作入口保留、标题不裁切 |
| Icom LAN Spectrum、CW Skimmer | 720、1080 × 模拟 96/144/192 | 不重排、不增加滚动条、图形区域可绘制 |
| 浅色 / 深色 | 上述 Dock 矩阵分别覆盖 | 文本颜色、画布和操作按钮均可绘制 |
| 连续缩放 | 75 → 125 → 100 → 85 → 100% | 按钮点击连续可用、原有控件顺序与尺寸恢复 |
| Windows 任务链 | 完整 xUnit + Compile Check + aislop + Docs | 检测自动化回归与质量门禁 |

所有截图是无电台连接的**模拟 WinForms 界面**，并非用户真实 SkyRoof 工作台截图。CI 通过仅证明模拟视图和代码逻辑，不能推断 IC-9700 / 真实 G-5500 实机已通过测试。

## 已知边界与发布决策

- **不宣称真实双显示器 PerMonitorV2 长时间运行、Wine 系统或多路业余卫星时的 GUI 已实测。** Windows CI 没有多台物理显示器及电台，无法观测真实桌面 DPI 切换、驱动焦点与刷新抖动。
- 程序默认保留 SystemAware；PerMonitorV2 可显式启用测试，并可随时恢复，不因模拟测试通过就默认切换。
- 缩小到极窄窗口时部分信息不可读属真实物理屏幕空间限制，提供同比例缩小和较大窗口的操作选择，不擅自隐藏发射或紧急 STOP 控件。
- 本文证据以对应 GitHub Actions 运行及上传附件为准；如构建或单测失败，则不能视为验收通过。
